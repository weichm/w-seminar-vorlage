# W-Seminar – Dein Arbeitsrepo

In deinem privaten GitHub-Repo dokumentierst du deine Arbeit, sammelst Literatur und hältst deine Lehrkraft über deinen Fortschritt auf dem Laufenden. Du kannst alle Schritte direkt im Browser erledigen.

## 1. Erstelle dein privates Repo

1. Melde dich bei GitHub an und öffne das öffentliche Vorlagenrepo.
2. Klicke auf **Use this template → Create a new repository**.
3. Wähle unter **Owner** dein eigenes GitHub-Konto. Nenne dein Repo zum Beispiel `w-seminar`.
4. Wähle **Private** und klicke auf **Create repository from template**. Prüfe anschließend, ob neben dem Namen deines neuen Repos **Private** steht.

Ab jetzt arbeitest du in deinem eigenen Repo. Prüfe vor dem Bearbeiten, ob dein Benutzername oben vor dem Repo-Namen steht.

## 2. Lade deine Lehrkraft ein

1. Öffne in deinem Repo **Settings → Collaborators → Add people**.
2. Suche nach dem GitHub-Benutzernamen **LEHRKRAFT-GITHUB-NAME** und sende die Einladung.
3. Sobald deine Lehrkraft die Einladung angenommen hat, kann sie deine Einträge lesen und dir im Repo Rückmeldung geben.

## 3. Führe Tagebuch und Literaturverzeichnis

| Datei | Was du einträgst |
| --- | --- |
| [Forschertagebuch.md](Forschertagebuch.md) | Halte nach einem wichtigen Arbeitsschritt kurz fest, was du gemacht hast, was dabei herauskam und was du als Nächstes vorhast. Begründe wichtige Entscheidungen. |
| [Literaturverzeichnis.md](Literaturverzeichnis.md) | Gib jeder neuen Quelle eine feste Kennung wie `Q01`. Notiere die vollständigen bibliografischen Angaben, die genaue Fundstelle und wofür du die Quelle brauchst. |

Öffne die gewünschte Datei und klicke auf das **Stiftsymbol**. Kopiere den Vorlagenblock aus der Datei und fülle ihn aus. Prüfe die Darstellung unter **Preview**. Klicke auf **Commit changes…**, gib eine kurze Beschreibung ein, etwa „Erste Quelle ergänzt“, und bestätige das Speichern.

Verweise im Tagebuch auf konkrete Fundstellen. Sobald du die Quelle unter der Überschrift `### Q01` erfasst hast, verlinkst du sie zum Beispiel mit `[Q01, S. 12](Literaturverzeichnis.md#q01)`.

## 4. Richte das Betreuungs-Issue ein (nein, wir verwenden Teams)

1. Öffne in deinem privaten Repo **Issues → New issue**. Falls der Reiter **Issues** fehlt, schalte ihn unter **Settings → General → Features** ein.
2. Gib dem Issue den Titel **Betreuung** und erstelle es.
3. Gib deiner Lehrkraft den Link zum geöffneten Issue.
4. Schreibe zum vereinbarten Termin einen **Kommentar im selben Issue**. Nenne jeweils ein Ergebnis mit Link zum Beleg, eine offene Frage (falls vorhanden) und deinen nächsten Schritt mit Termin.

Kopiere für deinen Check-in diese drei Zeilen und fülle sie aus:

```markdown
- **Ergebnis und Beleg:** …
- **Offene Frage (falls vorhanden):** …
- **Nächster Schritt bis [Datum]:** …
```

Du findest die Rückmeldung deiner Lehrkraft im selben Issue.
